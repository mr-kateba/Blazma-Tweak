**Blazma Tweak 0.2.0**

- **100 تحسين** بدل 60: تحسينات ألعاب متقدمة (دقة المؤقت، وضع MSI لكرت الشاشة، كرت الشبكة)، وخصوصية أكثر، وواجهة، وتحديثات، وخدمات.
- **«افحص جهازي»:** يقترح التحسينات المناسبة لجهازك (الرام، SSD، لابتوب أو مكتبي، الطابعة)، وزر «طبّق المقترح».
- **صفحة التطبيقات:** حذف تطبيقات ويندوز الزايدة، وترجيعها من المتجر.
- **صفحة بدء التشغيل:** تطفي البرامج اللي تشتغل مع الجهاز بدون حذف.
- **صدّر واستورد** إعداداتك، وأوامر بدون واجهة: `-Preset` و`-Apply` و`-Undo` و`-Config` و`-List`.
